# Phase 1: Brainstorming & Ideation

## Project Name
**FitBuddy – AI Fitness Plan Generator**

## Objective
To provide users with personalized 7-day workout routines and dietary strategies tailored to their unique fitness goals using Google Gemini AI models and FastAPI.

## Scenarios Addressed
1. **Goal-Based Routine:** Generates a custom workout based on user age, weight, and fitness targets.
2. **Dynamic Feedback Loop:** Adapts and alters the plan if the user requests modifications (e.g., adding cardio).
3. **Smart Nutrition:** Provides micro-dietary tips alongside the workout schedule.
4. **Admin Dashboard:** Enables trainers to monitor all user activities and metrics.
