# Phase 2: Requirement Analysis

## Hardware Requirements
* Operating System: Windows 10/11, macOS, or Linux
* RAM: Minimum 4 GB (8 GB Recommended)
* Internet Connection: Stable connection for Gemini API calls

## Software & Framework Requirements
* Programming Language: Python 3.9 or higher
* Web Framework: FastAPI
* Server: Uvicorn
* Database: SQLite (with SQLAlchemy ORM)
* Templating Engine: Jinja2 Templates
* Core Packages: google-generativeai, pydantic, python-multipart

## Core AI Models Integrated
1. **Google Gemini 1.5 Pro:** Used for parsing fitness goals and compiling structured 7-day workout plans.
2. **Google Gemini 1.5 Flash:** Used for rapid response generation of micro-dietary and nutrition tips.
